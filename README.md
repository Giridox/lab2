# My First Repo

A tiny Python project made during **Lab 2** to practise git and GitHub.

## How to run

```
python greetings.py      # or: python3 greetings.py (Mac)
```

## What's inside

- `greetings.py`: a few friendly functions (`greet`, `farewell`, `shout`, ...)
- `motto.txt`: our lab motto
```

## I am Giridhar
```

## I learnt Git and Github
- git init:	Turn a folder into a git repo
- git status:	Show what's changed / untracked
- git add <file>:	Stage a file for the next commit
